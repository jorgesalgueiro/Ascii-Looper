ASCII Looper - Comprehensive Manual

1. Workflow & Loop Controls

  • Setup: Ensure [ENABLE SYNC] is checked. Set BPM (e.g., 120) and Bars (e.g., 2). Press [T] to hear the metronome.
  • Record: Press any number [1-0]. The loop arms (Yellow). Recording starts automatically at the next bar (Red).
  • Play/Stop/Clear: Short press [1-0] to Play/Stop. Long Press on a Stopped loop to CLEAR it. Long Press on Playing loop to STOP immediately.
  • Overdub [+]: Press [+] to toggle Overdub Mode (Magenta). Press loop number to add audio. Feedback slider controls decay.
  • Substitute [-]: Press [-] to toggle Substitute Mode (Teal). Replaces old audio in real-time instead of adding to it.
  • Sustain [*]: Press [*] to toggle Momentary mode. Actions (Play/Record) only happen while the key is held down.
  • Loop Modifiers: Use UI buttons to RTRG (Retrigger on-beat), MULT (Double length), 1/2 (Half speed), or NORM (Normalize volume).

2. Modules & Workspaces

  • Input & Master Mix: Manage Mic or System Audio. Use the Console tab to mix loops, drones, and inputs. Apply global Master EQ/Comp here.
  • FX Chain: Type letters (e.g., QCATG) to reorder effects natively per loop. Import .afx bundles to load Custom AudioWorklet effects.
  • Drone Synth: 10 polyphonic synths. Features dual oscillators, Sub, FM, Filters, ADSR, and algorithmic rhythm generation (Euclidean/Chaos). Supports MIDI pitch-bend and mod-wheel.
  • Song Tracker: Sequence loops and drones. Create Patterns, arrange them in Song Mode. Commands: ON (Play), OFF (Stop), MUT (Mute), UNM (Unmute), LOP (Restart pattern).
  • Sample Lab: Offline DSP editor. Extract audio from loops, apply high-quality SoundTouch time-stretching (sync to bars) or pitch shifting, and send it back.

3. MIDI & Key Mapping

  • MIDI Learn: Right-click almost any slider/knob to enter "MIDI Learn" mode, then move a knob on your MIDI controller to assign it. Press [ESC] to cancel.
  • Mappings: Use the [CONFIG] tab to manually assign Keyboard, MIDI Notes, and Gamepad buttons.
  • Transport: Standard MIDI Play/Stop/Continue messages map automatically to the Tracker.

4. Global Hotkeys

[1]-[0] Loops 1-10 [Space] Stop All
[Q]-[P] Drones 1-10 [R] Record Master
[+] / [-] / [*] Overdub / Sub / Sus [H] Half Speed
[Z] / [Sh]+[Z] Undo / Redo [M] / [N] Master Rec / Metronome

5. File Types

  • .alp: Project File (Contains settings & audio).
  • .wav: Exported Audio (Loops, Mixes, Samples).
  • .trk: Tracker Song Sequence.
  • .afx: Custom AudioWorklet & Preset Bundle.
  • .acp / .agp / .ald: FX Chain, Global, and Drone Presets.

7. Pro Tips

  • Latency Calibration: Always run the PING TEST in the [TIMING] tab with your speakers on to auto-calibrate roundtrip latency.
  • Effect Reordering: Type letters directly into the FX Chain box (e.g., "D" before "T" for delay into distortion) to radically change the sound.

ASCII Looper - Manual Completo

1. Flujo de Trabajo y Controles de Loop

  • Configuración: Active [ENABLE SYNC]. Ajuste los BPM y Compases (Bars). Pulse [T] o el Metrónomo para escuchar la claqueta.
  • Grabar: Pulse un número [1-0]. El loop se arma (Amarillo) y graba al inicio del compás (Rojo).
  • Play/Parar/Borrar: Pulsación corta para Play/Stop. Pulsación Larga en loop Parado borra la pista. Pulsación Larga en loop sonando hace un corte de inmediato.
  • Overdub [+]: Pulse [+] (Magenta). Añade audio sobre la capa existente. El nivel de decaimiento se controla con el slider "Fbk".
  • Sustituir [-]: Pulse [-] (Turquesa). Reemplaza el audio antiguo en tiempo real en lugar de sumar (Punch-in destructivo).
  • Sustain [*]: Pulse [*]. Las acciones de Grabar/Play solo ocurren mientras mantenga la tecla presionada (Momentary).
  • Modificadores: Use los botones de la interfaz para RTRG (Reiniciar a tiempo), MULT (Doblar duración), 1/2 (Media velocidad), o NORM (Normalizar volumen).

2. Módulos y Espacios de Trabajo

  • Input & Master Mix: Administre entradas de Micrófono o Sistema. Use la consola maestra para mezclar pistas, drones y ecualizar globalmente.
  • FX Chain: Escriba letras (ej. QCATG) para reordenar efectos. Importe paquetes .afx para cargar efectos personalizados basados en AudioWorklets.
  • Drone Synth: 10 Sintetizadores polifónicos. Incluye osciladores duales, Sub, FM, ADSR y generación rítmica Euclidiana/Caos. Soporta rueda de modulación y Pitch Bend MIDI.
  • Song Tracker: Secuencie loops y drones de forma automática. Comandos de celda: ON (Tocar), OFF (Parar), MUT (Mutear), UNM (Desmutear), LOP (Reiniciar patrón).
  • Sample Lab: Editor DSP Offline. Extraiga audio de un loop, aplique Time-Stretch de alta calidad (SoundTouch) sincronizado a compases o cambie el tono, y envíelo de vuelta.

3. MIDI y Mapeo

  • MIDI Learn: Haga clic derecho en casi cualquier control deslizante para entrar en modo "MIDI Learn", luego mueva una perilla en su controlador MIDI para asignarla. Pulse [ESC] para cancelar.
  • Mapeo: Use la pestaña [CONFIG] para asignar Teclado, Notas MIDI o botones de Gamepad manualmente.
  • Transporte: Mensajes estándar MIDI de Play/Stop/Continuar mapean automáticamente al Secuenciador (Tracker).

ASCII Looper - Manual Completo

1. Fluxo de Trabalho e Controlos de Loop

  • Configuração: Ative [ENABLE SYNC]. Ajuste o BPM e os Compassos (Bars). Prima [T] ou o Metrónomo para ouvir a marcação de tempo.
  • Gravar: Prima um número [1-0]. O loop é armado (Amarelo) e começa a gravar no compasso seguinte (Vermelho).
  • Tocar/Parar/Limpar: Pressão curta para Play/Stop. Pressão Longa num loop parado limpa-o. Pressão Longa num loop a tocar para-o imediatamente.
  • Overdub [+]: Prima [+] (Magenta). Adiciona áudio por cima da gravação existente. O decay é controlado pelo slider "Fbk".
  • Substituir [-]: Prima [-] (Ciano). Substitui o áudio antigo em tempo real em vez de o somar (Punch-in destrutivo).
  • Sustain [*]: Prima [*]. As ações de gravação/reprodução apenas ocorrem enquanto a tecla estiver premida (Momentary).
  • Modificadores: Use os botões da interface para RTRG (Reiniciar no tempo), MULT (Dobrar duração), 1/2 (Meia velocidade), ou NORM (Normalizar volume).

2. Módulos e Espaços de Trabalho

  • Input & Master Mix: Gira as entradas de Microfone ou Sistema. Use a aba "Console" para misturar loops, drones e equalizar a saída master globalmente.
  • FX Chain: Escreva letras (ex: QCATG) para reordenar efeitos. Importe pacotes .afx para carregar efeitos personalizados baseados em AudioWorklets.
  • Drone Synth: 10 Sintetizadores polifónicos. Inclui Osciladores duplos, Sub, FM, ADSR e geração de ritmo Euclidiana/Caos. Suporta Pitch Bend e Mod Wheel via MIDI.
  • Song Tracker: Sequencie loops e drones automaticamente. Comandos: ON (Tocar), OFF (Parar), MUT (Mute), UNM (Unmute), LOP (Reiniciar padrão).
  • Sample Lab: Editor DSP Offline. Extraia áudio de um loop, aplique Time-Stretch de alta qualidade (SoundTouch) sincronizado com os compassos ou Pitch Shift, e envie-o de volta.

3. MIDI e Mapeamento

  • MIDI Learn: Clique com o botão direito em quase qualquer controlo deslizante, depois mova um botão no seu comando MIDI para o atribuir. Prima [ESC] para cancelar.
  • Mapeamento: Use a aba [CONFIG] para atribuir manualmente botões do Teclado, Notas MIDI ou Gamepad.
  • Transporte: Mensagens padrão MIDI de Play/Stop/Continuar mapeiam automaticamente para o Sequenciador (Tracker).
